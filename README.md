# 刀鱼听书 1.0.0（第一期）

安卓电子书阅读 + 听书 App。Kotlin + Jetpack Compose，最低 Android 8.0。

## 已实现
- **书架**：封面墙、继续阅读卡片、无封面书自动生成封面、长按查看详情 / 删除
- **格式**：TXT（自动识别 UTF-8 / GBK / GB18030 / Big5 编码、自动分章、清理分隔线）、EPUB（目录、封面、正文）
- **阅读**：霞鹜文楷 / 思源宋体 / 系统黑体 / 自定义字体；字号、行距、边距、首行缩进、加粗；
  两端对齐与标点避头尾；6 种背景（含夜间、纯黑）；平移 / 覆盖 / 无动画翻页；
  点按左右翻页、中间呼出菜单；音量键翻页；亮度调节；目录、书签；页眉页脚（时间、电量、进度）
- **WiFi 传书**：手机开启后显示地址和二维码，电脑浏览器拖拽上传，也能在网页上下载 / 删除书
- **听书**：微软 Edge（免费）、阿里云 CosyVoice、Google Gemini、系统朗读四个引擎，
  播放面板随时切换，每本书可固定引擎；朗读句高亮、自动翻页；提前合成 + 缓存；
  锁屏 / 通知栏 / 耳机线控；定时关闭（15/30/60 分钟、本章结束）；
  失败自动降级（Gemini → CosyVoice/Edge → 系统朗读），月用量上限与费用估算
- **长按正文**：从这里开始听书 / 添加书签

## 1.1 多角色说书
- 听书面板「模式」：单人说书 / 多角色，听书中可随时切换，进度共用
- 多角色：旁白用免费微软 Edge，对白由通义千问 Qwen3-TTS 按角色配音；说话人由通义千问 Plus 分析（同一个阿里云 Key）
- 每本书一张角色表：自动识别角色、别称、性别年龄并分配音色；可换音色、试听、合并同一人；可提前分析后续章节
- 长按正文：改说话人 / 这一句重新合成
- 费用约 65 元 / 百万字（旁白免费，对白 ≈1.5 元/万字，角色分析 ≈3–5 元/百万字）

## 1.2 多角色改进
- 角色分析：强调词、牌匾、俗语等引号直接归旁白；新提示词按"说话提示语 → 轮流对话"判断并写出依据；修正短句对白对不上号被当成路人的问题
- 定制音色：说话 3 句以上的角色按分析出的年龄、嗓音、性格用千问「声音设计」生成专属音色（0.2 元/个，每本书最多 30 个），男声固定在中低音域并做音高校验
- 角色表可查看 / 修改每个角色的声音描述，并按描述重新设计
- 旧版分析结果在播放时自动按新方法重新分析，手动改过的说话人保留

## 1.3 豆包对白
- 多角色模式的人物对白默认改用豆包语音合成 2.0（火山引擎，中文盲听评测第一），旁白仍为免费 Edge
- 内置 210 多个豆包音色（含老年、中年阿姨、奶奶等）（中年/老年/青年/少年/儿童，男女），由角色分析模型按角色描述自动挑选；角色表可试听、手动换
- 每句情绪作为语音指令传给豆包（不计费）；Key 无效或额度用完自动改用通义千问
- 设置里新增「豆包语音（火山引擎）」Key、月上限；用量与费用（约 2.8 元/万字）

## 1.3.3 章节衔接
- 角色分析改为流式调用（不再因单次回复超过 90 秒而超时重试）
- 每章切成约 30 句一段并行分析，正在听的章节优先，后面三章在后台提前分析
- 默认分析模型改为千问 Max（与 Plus 一样准、快一倍）；可改用 Flash 省钱

## 1.3.4 内容审核误拦
- 阿里云百炼对输入做内容审核，普通网文偶尔被误拦（Input data may contain inappropriate content）
- 被拦的段落自动对半拆开重试，直到只剩一两句；拆到最后仍被拦的句子按"某某道"规则判断说话人，其余照常分析，不再整章失败

## 1.3.5 Grok
- 设置里可填 xAI Grok Key：被千问审核拦下的段落整段交给 Grok 分析（不受国内审核，需代理）
- 角色分析模型也可直接选 Grok；代理没开时自动改用千问 Max，10 分钟后再试 Grok

## 1.3.6 音色稳定、豆包旁白
- 角色的音色一旦用过就固定；配音失败时在这一句暂停并说明原因，不再悄悄换成别的引擎或音色
- 播放出错的句子重新合成一次，仍失败就暂停，不再跳过
- 微软 Edge 现在拒绝本 App 访问，多角色的旁白默认改用豆包（约 2.8 元/万字），可在设置、角色表、听书面板里换旁白音色或切回 Edge
- 角色分析默认模型 qwen3-max 已被阿里云下线，改用 qwen3.8-max，旧设置自动迁移

## 1.3.7 无名配角、Grok 兜底
- 没名字但身份明确的配角（卖花女孩、店小二）作为独立角色配音，不再用旁白的声音读；其余无名人物按男女分别用路人男声、女声
- 千问分析本身出错（模型下线、超时、额度用完）时也改用 Grok（需填 Grok Key 并开代理）
- 角色分析结果格式升级，已分析的章节播放时会重新分析一次，手动改过的说话人保留

## 1.3.8 配音情绪更贴合
- 角色分析给每句台词标情绪强度：平静的话自然地说，激动的话才演足，不再句句用力
- 豆包配音时参考前文，语气衔接更自然
- 角色分析结果格式升级，已分析的章节播放时会重新分析一次，手动改过的说话人保留

## 1.3.9 旁白音色不再忽变
- 修复 1.3.8 的旁白时而像换了个人：旁白不再参考前文（带上角色台词后豆包会把旁白读得更高更亮）；角色对白只参考前面的旁白，不再参考别人的台词

## 1.3.10 豆包配音音量拉平
- 豆包每次合成的音量会随机浮动 3～7 分贝，旁白偶尔听着忽然变小；现在每段合成后自动拉到同一音量（对白也一样）
- 豆包音频改存 WAV，缓存占用变大，已合成的豆包音频会重新生成一次

## 1.3.11 角色对白不再被认成路人
- 修复部分章节里主角的对白被当成路人：模型偶尔漏写说话人，现在回复改用带字段名的格式，漏写时自动重问，仍不行就按"某某道"和对话轮流推断
- 只说一两句的有名配角（如杨泉）不再归为路人；只用代称（他、老者）的已知角色也按名字配音
- 角色分析结果格式升级，已分析的章节播放时会重新分析一次，手动改过的说话人保留

## 1.4.0 书源搜书
- 书架右上角新增「搜书」：在你自己添加的书源里搜索书名或作者，下载后自动加入书架，可直接阅读和听书
- 书源 = 网站地址 + 搜索 / 解析规则，在「书源」页新建、编辑、开关、删除；网站改版或失效时改规则或换一个书源即可
- 两种下载方式：网站提供 TXT / EPUB 文件的直接下载；网站按章节展示的逐章抓取后合成一本书（支持目录分页、正文分页、净化广告文字）
- 兼容「阅读」(Legado) 书源 JSON 的字段，可粘贴单个或一组导入、一键导出；规则支持 CSS、阅读默认语法、JSONPath、XPath，不支持 JavaScript
- 编辑页可「测试」：不保存就能用当前规则跑一遍搜索 → 详情 → 下载链接 / 目录和第一章
- 内置一个公版示例：古腾堡计划（Project Gutenberg），不内置任何其他站点；请只使用你有权下载的正版或公版资源

## 1.4.1 简繁体自动重搜
- 搜书时某个书源没有结果，自动换成繁体（或简体）再搜一次：古腾堡里的中文古籍书名是繁体，现在直接搜「红楼梦」也能找到

## 1.4.2 AI 添加书源
- 「书源」页顶部新增「AI 添加书源」：只填网站地址和一本这个网站上有的书名，千问自动读网页、写好搜索 / 详情 / 目录 / 正文规则，并实际搜一遍、取一章确认能用，成功后一键保存
- 写错了会把失败原因告诉 AI 重写，每一步最多试 3 次；写不成时可以保存已写好的部分再手动改
- 用设置里的阿里云 Key，一次大约几分钱，计入「本月用量」的角色分析
- 网站要登录、有人机验证、或结果完全靠 JavaScript 加载时写不出来

## 1.4.3 AI 添加书源修复
- 修复首页没有搜索框时 AI 判断搜索地址直接报错（千问 400：messages must contain the word 'json'）
- AI 也判断不出搜索地址时，自动试常见的搜索地址（/search?q=、/search.php?searchkey= 等），哪个结果页里有这本书就用哪个

## 1.4.4 书源测试诊断
- 书源编辑页点「测试」时，哪一步没取到东西（搜索没结果、没有下载链接、目录为空、出错），会列出网站实际返回的内容：请求地址、请求体、状态码、内容类型、页面标题和开头一段
- 搜索没结果时说明原因：返回的是网页还是 JSON、「结果列表」匹配到几个、有几个取到了书名
- 测试结果可以长按选择，也可以点「复制测试结果」整段复制；请求头只列名字，不显示 Cookie 等的值

## 1.4.5 书源保存 Cookie
- 书源请求会像浏览器一样保存网站下发的 Cookie（App 运行期间有效），修复有的网站先下发 Cookie 再跳转、App 不带回去导致一直跳转（Too many follow-up requests）
- 书源请求头里自己写的 Cookie 会保留，和网站下发的一起发送，同名时以自己写的为准
- 测试诊断里列出跳转经过；还在一直跳转时，提示可能要登录、人机验证或网站不接受 App 的请求

## 1.4.6 网页导入
- 搜书页右上角新增「网页导入」：App 里的浏览器，像平时一样打开网站、搜书，点 TXT / EPUB 的下载链接，书自动下载并加入书架，不用写任何规则
- 在里面登录过的网站会记住登录状态，下载时带上；最近访问的网站显示在首页，点一下就能打开
- 也可以继续用手机浏览器下载，在文件上选「用刀鱼听书打开」导入

## 首次使用建议（OPPO Find X8 Ultra / ColorOS）
1. 设置 → 后台听书保护 → 「忽略电池优化」点「去允许」
2. 应用信息 → 耗电管理 → 打开「允许后台行为」；在多任务界面下拉锁定刀鱼听书
3. 设置里填写 CosyVoice、Gemini 的 API Key，各点一次「试听」确认可用

## 构建
```
./gradlew assembleRelease     # 输出 app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest   # 解析器、分句、Edge 语音联调、界面截图（app/build/shots）
```
签名文件与密码不在源码包中：把你的 `daoyu.jks` 放到 `keystore/`，按 `keystore.properties.example` 建一个 `keystore.properties`，再执行 assembleRelease。以后升级必须用同一个签名。
